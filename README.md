# TurnProof｜旋转摄影台

把电商转台的正向照片按拍摄台位归档。现场可以比对原片和补拍、检查底座标记的画面跳动，再封存人工确认的一圈供回看和交付。

在目录内运行 `./start.sh`，打开 [旋转摄影台](http://127.0.0.1:19902/)。`TURNPROOF_PORT` 可设置本机端口，`./start.sh stop` 停止服务并保留数据卷。也可安装 `requirements.txt` 后运行 `python -B -m turndesk`。

1. 新建 6、8、12、18 或 24 个等角度台位的转台，或打开注明合成性质的陶瓷包装六面样片。
2. 在台位导入照片，已有照片时保留为补拍。点击缩略图显示该张原片，决定是否手动采用。
3. 在原照中点底座同一个定位点，可以清除后重标。将想保留的照片标为细节首选，锁定已确认的角度。
4. 在“曝光检测”读近白、近黑比例及亮度分布。“打开照片准备”可裁切、校色或合成照片，再把结果送回同一台位。
5. 在“相邻过渡”逐对看当前采用照片及归一化落点变化，包含末张回到首张。定位点未齐时显示缺证。
6. 在“循环回看”按台位逐张检查或自动循环，打开联系表看当前采用的一整圈。
7. 封存一整圈后，可重开相同原照、定位点和相邻变化，下载联系表、单张原照和 ZIP。ZIP 含角度顺序、原片证据和 SHA-256。

输入为单帧 PNG、JPEG 或 TIFF。每张最高 12 MiB、320 万像素、长边 8192 像素，每台位最多保留 3 张，工程正向 PNG 总量限 160 MiB。原片在 EXIF 转正后存为 RGB PNG，透明像素用白底显示，定位是转正后的像素坐标。相邻跳动按横、纵像素分别映射到各自画面比例后求距离，表达百分比，供现场照片检查。回看按固定台位切换原片，允许逐张或循环查看。
